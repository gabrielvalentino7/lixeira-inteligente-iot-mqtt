# Documentação da Comunicação MQTT

Este documento descreve a comunicação MQTT utilizada no projeto **Sistema Inteligente de Monitoramento de Lixeiras Urbanas utilizando IoT**.

## Protocolo utilizado

O projeto utiliza o protocolo **MQTT**, que é um protocolo leve de comunicação baseado no modelo de publicação e assinatura, conhecido como **publish/subscribe**.

Esse modelo é adequado para aplicações de Internet das Coisas porque permite que dispositivos enviem e recebam dados de forma simples, com baixo consumo de recursos.
